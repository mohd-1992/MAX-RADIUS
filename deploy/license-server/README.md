# مكونات اعتماد مفتاح النسخة عند التفعيل

هذه مكونات إصدار لخادم التراخيص المنفصل، وليست تطبيق MAX المستأجر ولا نسخة كاملة من خادم الإصدار. المصدر المعتمد لخادم الإصدار max-license-server مستقل؛ يطبق هذا الإصدار على نسخة كاملة متوافقة منه بعد حفظ المصدر ومفاتيح الإصدار وقاعدة SQLite. لا تدخل هذه الملفات صورة العميل ولا تنقل أي مفتاح خاص إليها.

تشمل ملفات التطبيق والأمان والقالب والاختبار المتأثرة، كي تحفظ التعديلات في مستودع الإصدار مع العميل. بدء install_protocol ينشئ جدول master_enrollment_tokens دون تعديل التراخيص الحالية. الاختبار tests/test_instance_enrollment.py يعمل في SQLite مؤقتة ويحتاج ملف بروتوكول العميل المحدد عبر MAX_CLIENT_PROTOCOL_TEST_PATH عند اختلاف مجلد المشروع.

الأثر: التنزيل والنسخ من اللوحة يولدان ملف تفعيل بإذن24ساعة يستخدم مرة واحدة للاعتماد الأول. النبضات القديمة للنسخ المعتمدة متوافقة. ملفات الترخيص القديمة تحتاج تنزيل نسخة تفعيل جديدة للنسخ غير المعتمدة؛ لا يتغير توقيع الترخيص أو مدته أو حدوده. راجع docs/LICENSE_ENROLLMENT.md في جذر مستودع العميل.
