# إدارة المشتركين: حدود تعديل البيانات

تصحيح24أكتوبر2026 في المصدر المحلي: [فاتورة البوابة وسجل التعديل](PORTAL_INVOICE_AUDIT_FIX_20261024.md). فاتورة شراء المحفظة ضمن المعاملة؛ تبويب التعديل يسجل التغييرات مرة واحدة دون كلمات مرور، ويعرض JSON القديم بالعربية دون حذف التاريخ. لم تُبنَ أو تُنشر صورة بهذا التصحيح.

مسارات `web/routes/subscribers.py` تحمي العرض والإنشاء والتعديل والحذف والفصل والفواتير بصلاحيات RBAC. إجراءات `web/routes/system.py` المشتركة تختار الصلاحية حسب العملية ونوع الحساب؛ تعديل المحفظة يتطلب `wallets.manage`. طلبات POST للمشتركين وإجراءات الحسابات والفواتير تحتاج CSRF؛ النماذج تحمل الحقل والـfetch المشترك يرسل الترويسة إلى نفس الموقع فقط.

`subscriber_service.create_subscriber/update_subscriber` يحفظ بيانات المشترك ومزامنة جداول RADIUS والتدقيق في اتصال ومعاملة واحدة. فشل المزامنة أو التدقيق يلغي الكتابات. هذا ضمان لاتساق قاعدة البيانات، ولا يثبت تطبيق سياسة جديدة على جلسة NAS متصلة.

تعديل محلي غير منشور بتاريخ24أكتوبر2026: تبويب التعديل يستخدم `edit_subscriber_contract` للاسم والصلاحية ونوع الخدمة والربط والبيانات الشخصية. تغيير الصلاحية يحتاج إذن التجديد والمنح التفصيلي لتمديد الوقت، ولا يضيف بيانات أو يبدأ دورة. الإيقاف اليدوي واستنفاد الحصة لا يلغيهما تمديد التاريخ. الحالة تبقى للعرض. المسار القديم `edit_subscriber_action` يبقى للبيانات الشخصية فقط.

تغيير اسم الدخول يثبت ملكية التاريخ بمعرّف المشترك، مع إبقاء اسم حزمة RADIUS الأصلي وUID والعدادات والتواريخ الفعلية دون تغيير. الاسم السابق محجوز للتاريخ ولا يعاد منحه لحساب آخر. واجهات القراءة `*_owned` تعرض الهوية الحالية والاسم الأصلي منفصلًا، وتشمل القراءات المسؤولة عن الحصة وFreeRADIUS؛ لا يكفي نشر Web وحده مستقبلًا. يتبع رصيد نقاط الولاء الاسم الجديد، وتبقى سجلات العمليات الأصلية محفوظة. تغيير الاسم/الخدمة/MAC/IP يتطلب تسوية اتصالات هذا المشترك أولًا؛ قبول الفصل وحده ليس Stop. فشل التسوية يرفض الحفظ برسالة قابلة للعرض.

قسم تغيير الباقة في التبويب له حفظ مستقل ويستدعي `action_change_package` الموجود: دورة جديدة وخيار الترحيل وتسوية السلفة وفق السلوك السابق. المحدود إلى المفتوح والعكس والأعلى والأقل مسموح، والتحميل المفتوح لا يرحّل إلى رصيد رقمي. يلزم إذنا التعديل والتجديد والمنح التفصيلي لتغيير الباقة. إيصال الطلب المربوط بالمشترك والمنفذ والبيانات يمنع تكرار العملية نفسها؛ ومراجعة النسخة وقفل الصف يمنعان الكتابة من صفحة قديمة.

[نتائج التعديل المحلي وحدود المعاينة](SUBSCRIBER_EDIT_LOCAL_RESULTS_20261024.md). لا تحديث دومين أو صورة منشورة ضمن هذا الطلب.

إيداع وسحب المحفظة في `quick_action_service._change_wallet_balance` يستخدمان Decimal وقفل صف `FOR UPDATE` على MariaDB، ثم تحديث الرصيد والفاتورة للمشترك والتدقيق في معاملة واحدة. السحب يفحص الرصيد بعد القفل. الكروت تحتفظ بالسلوك السابق دون فاتورة مشترك. لا يوفر هذا مفتاح منع تكرار لطلب يُعاد إرساله؛ معالجة IDs المكررة في العمليات الجماعية مسألة مستقلة.

الفحص المعزول: `python -m unittest discover -s tests -p test_subscriber_admin_safety.py -v`. يغطي صلاحيات المسارات وCSRF والتراجع ومزامنة RADIUS وحماية العقد ومخرجات القوالب. لا يشغّل عمال التطبيق أو جلسات الراوتر.

القائمة تقرأ استهلاك الدورة عبر `quota_service.get_subscriber_accounting_totals_batch` بقطع من 400 حساب، وفق حساب جداول radacct وخطوط الأساس الذي تستخدمه المحاسبة الرسمية. بداية الدورة: آخر تجديد، ثم أول استخدام، ثم الإنشاء. الجلسة العابرة للدورة دون baseline تجعل الاستهلاك غير متاح لذلك الحساب؛ فشل استعلام المحاسبة يجعل القيم غير متاحة للقائمة، دون اعتبارها صفرًا. هذا عرض لعدادات DB، وليس checkpoint حيًا للراوتر. snapshot صفر يحافظ على الكوتا المفتوحة ولو كانت extra_quota موجبة.

الطلبات الجماعية تتحقق من جميع معرفات الحسابات قبل أي تنفيذ وتزيل التكرار بعد تطبيع الأرقام (`1` و`01` نفس ID). الإجراء غير المعروف مرفوض. هذه حماية من التكرار داخل الطلب الواحد، وليست منع تكرار بين طلبين منفصلين.

قيم أزرار العمليات تستخدم JSON مهربًا لسياق سمة HTML، ومعاينة اسم الباقة تستخدم textContent. صلاحية صفر تعرض «غير محدودة»، والوحدات يوم/ساعة/دقيقة/شهر بالعربية؛ الرجوع إلى validity_days عند غياب القيمة الحديثة فقط، دون استبدال الصفر.

فحص النقاط 5–8: `python -m unittest discover -s tests -p test_subscriber_list_safety.py -v`؛ محاسبة SQL وbaselines، تجميع IDs، أثر المحفظة، وصحة معالجات الأزرار ومعاينة الباقة في JavaScript. لا يعد فحص Node اختبارًا بصريًا للمتصفح.
