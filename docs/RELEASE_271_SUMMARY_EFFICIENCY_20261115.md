## التغيير

- `backup_usage_summary.py` و`summary_backup_encoding.py`: كتابة الحقول المشتركة للملخصات بقواميس SQL وJSON_TABLE بدل تكرارها في كل صف. تستعاد المفاتيح والأزمنة الدقيقة والعدادات الصحيحة والجودة نفسها؛ الصفوف القديمة التي لا يمكن إعادة مفتاحها بأمان تستخدم VALUES الأصلي. لا تجميع زمني يفقد التفاصيل، ولا تغيير للـschema أو الحصة أو شروط أهلية التلخيص والأختام.
- حفظ البيانات الحية والملخصات وسجل المبيعات؛ التغيير يخص إنشاء النسخ التالية ولا يعيد كتابة النسخ القديمة أو ينفذ حذفًا حيًا.
- `dashboard_reporting_service.py`: استعمال تعبير مبلغ الفاتورة بدل استبدال نص قديم لم يعد يطابق تعبير تكلفة التقرير منذ r35. لوحة التحكم تحتفظ بمبلغ الفاتورة، وتقرير المشتركين يحتفظ بالتكلفة المسجلة للجديد ومبلغ الفاتورة القديم وفق عقده. لا UPDATE مالي.
- نفس gzip بالمستوى 6 وZ_FILTERED، ونفس قارئ الأرشيف. لم تضاف مكتبات؛ تطابقت حزم التشغيل الـ41 وعقد البدء والطبقات الموروثة.
