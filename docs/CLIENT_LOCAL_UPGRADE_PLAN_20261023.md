# خطة تحديث حاويات العميل المحلي

حُفظت هذه الخطة في 23 أكتوبر 2026 بطلب الإنسان للرجوع إليها لاحقًا. حالة العمل مؤجلة؛ لا تشغيل أو جدولة أو تثبيت أو اتصال بالعميل ضمن حفظها. المقصود مبدئيًا العميل المحلي المعروف باسم CLIENT_AS، وتثبت هويته الحية قبل التنفيذ. المراقبة الدورية تبقى متوقفة.

## الهدف والنطاق

تحديث المكونات المطلوبة على مراحل، مع تقليل توقف الخدمة وحفظ تصحيحات العميل وإمكانية الرجوع. آخر مرجع مقبول للعميل مؤرخ 22 أكتوبر 2026؛ لا يثبت حالته الحالية. صورته تتضمن تصحيحات خاصة به، ومنها معالجة النسخ إلى Telegram، فلا يستبدل محتواها بصورة أحدث قبل مقارنة الاعتماديات والسلوك.

[الإصدار 2.6.5](RELEASE_20261023_265.md) يغير Web فقط، وعروضه الحالية مقيدة بالدومينات m وmax1 وshn. تحديث العميل المحلي يحتاج مسارًا مثبتًا خاصًا به؛ لا تستخدم هوية أو عرض دومين له، ولا توسع الإتاحة العامة أو المحلية لبقية العملاء.

## الفحص والتجهيز قبل الانقطاع

1. تثبيت هوية جهاز العميل ومشروع Compose والحاويات الفعلية وبصمات الصور والمجلدات والتخزين ومنافذ NAS. تقارن الصور المرشحة بالحالية لتحديد الخدمات التي تحتاج تبديلًا فعلًا.
2. تحديد تصحيحات العميل التي يجب حفظها، ومراجعة توافق Web وCore والمخطط والتريغرات والترخيص ومسار التحديث المحلي. لا يعتمد رقم النسخة أو latest وحده لإثبات التوافق.
3. تجربة الصور المرشحة والتراجع على نسخة بيانات معزولة، بلا اتصال براوترات العميل أو تراخيص إنتاجه أو Telegram أو عماله الخارجيين. تشمل التجربة آثار التهيئة التلقائية عند بدء Web؛ حقل migration=none لا يكفي لنفيها.
4. تجهيز نسخة أمان حديثة ومتسقة ومشفرة لقاعدة البيانات والتخزين والإعدادات، والتحقق منها خارج الجهاز. تحفظ الصور والحاويات السابقة وطبقاتها القابلة للكتابة وملفات Compose والروابط الحالية.
5. تنزيل الصور مسبقًا وتثبيتها ببصمات محددة، مع قياس موارد الجهاز ووقت بدء المرشح والرجوع في المختبر. يجرى التنزيل والنسخ والخدمة تعمل، خارج نافذة التبديل قدر الإمكان. [تثبيت الصور بالبصمة في Docker](https://docs.docker.com/reference/cli/docker/image/pull/).

## ترتيب التحديث

| المكون | الإجراء المقترح | شرط القبول |
| --- | --- | --- |
| Web | تبديل منفصل أولًا بعد نجاح التجربة | توقيع وواجهة وترخيص وlease حديثة، مع حفظ بيانات العميل والتوافق |
| FreeRADIUS Core | خطوة مستقلة إن ثبت اختلاف مطلوب عن الإصدار المعتمد | مصادقة طبيعية ومحاسبة NAS وتقدم العدادات الفعلية بعد التبديل |
| MariaDB | نافذة مستقلة إن احتاج المحرك ترقية فعلية | تجربة ترقية ورجوع مدروسة تحفظ أحدث البيانات؛ لا رجوع ثنائي على مخزن غير متوافق |
| L2TP | تغيير مستقل عند الحاجة | بقاء أو عودة النفق الفعلي وإدارة العميل؛ يحمى مسار الوصول قبل تبديله |
| Autoheal | يراجع توافقه مع هوية الحاويات الجديدة | لا إجراءات متعارضة أو استهداف لحاويات قديمة أثناء التبديل |

تبقى DB وCore وL2TP تعمل أثناء خطوة Web. يمنع تشغيل نسختين كاملتين من Web بعمال الخلفية على قاعدة الإنتاج نفسها. تراجع سياسة Autoheal أثناء التبديل وتنسق بصورة محدودة بدل إيقاف جميع خدمات الجهاز.

مدة lease قصيرة في آلية التشغيل الحالية؛ يقاس المتبقي الفعلي قبل التبديل، ويجهز الرجوع بحيث لا تترك Web الجديدة متعثرة حتى انقضاء التصريح. استمرار Core وحده لا يضمن استمرار قبول دخول جديد إذا انتهت lease.

عند تبديل Core، تحدد نافذة هادئة وتراجع إعادة إرسال طلبات المصادقة والمحاسبة لدى NAS. لا يفصل المشتركون جماعيًا، ولا يدعى انعدام فقد الحزم من نجاح أمر Docker أو healthy.

## التحقق والرجوع

قبل التبديل تحفظ لقطة محددة لهويات الصفوف والعدادات والعقود والأرصدة والتريغرات، مع أعداد الجلسات ومطابقتها مع NAS. بعده يتحقق التوقيع والبصمة والواجهة والترخيص وlease، ثم مصادقات طبيعية وInterim وStop عند حدوثهما وتقدم العدادات دون تراجع أو ازدواج. لا تعاد عمليات مالية أو تجديدات لاختبار التحديث.

يشغّل مراقب تبديل محدد المدة ومستقل عن Web وSSH، لا مراقبة دورية مستأنفة. تحدد معايير فشل ومهلة قبول قبل التنفيذ ويختبر الرجوع. عند فشلها يعاد المكون السابق المتوافق مع أحدث البيانات، مع حفظ دليل المحاولة وعدم تكرار أوامر مجهولة النتيجة. لا تستعاد قاعدة تاريخية فوق محاسبة جديدة.

## الانقطاع المتوقع ونقطة الاستئناف

هدف خطوة Web توقف اللوحة لعشرات الثواني، ويثبت الزمن بالتجربة قبل تحديد النافذة. تحديث Core قد يوقف استقبال الطلبات لحظيًا، وترقية DB أو L2TP قد تحتاج انقطاعًا أطول منفصلًا؛ لا وعد بصفر انقطاع.

عند عودة الإنسان لهذه الخطة، يبدأ العمل بفحص الهوية والتوافق للقراءة ثم تجهيز نتيجة قابلة للمراجعة؛ لا تعاد مشغلات نشر أو نسخ أو اختبارات مالية من جولات قديمة. مرجعا التنفيذ [DEPLOYMENT](DEPLOYMENT.md) و[ENVIRONMENTS](ENVIRONMENTS.md)، والتحقق [TESTING](TESTING.md).
