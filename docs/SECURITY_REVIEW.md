# مراجعة الأسرار والتغليف —13 أكتوبر 2026

نتائج قراءة فقط، وليست شهادة اختراق أو دليل تسريب لمفتاح فريد. التفاصيل المحلية في security-scan-private.json تعرض مسارات وأنواعًا دون القيم.

## النتائج المؤكدة

- ملفات storage المتتبعة هي المفتاح العام و.gitkeep فقط. لم يكشف المسح النمطي أصل PRIVATE KEY أو token معروفًا في الملفات المتتبعة؛ لا يضمن ذلك غياب كل أنواع الأسرار أو سلامة تاريخ Git.
- يستخدم LOCAL بعض القيم الافتراضية الموجودة في كود وتهيئة متتبعة وعامة. شملت المطابقة core/config.py وملفات Compose و env.example ومخطط SQL و entrypoints وسكربتات تثبيت وقوالب NAS. ثبتت المطابقة مع LOCAL، ولم تثبت مع VPS. الخطر هو إعادة استخدام اعتماد منشور، وليس دليلًا على تسريب اعتماد VPS أو مفتاح ترخيص خاص.
- بعض الملفات المتأثرة تدخل صورة التطبيق أو Core/L2TP. حذف القيمة من Markdown أو إضافة ignore لا يزيلها من الكود أو الصورة أو التاريخ. لم تُغير هذه الجولة الكود أو الصور أو كلمات المرور.
- deploy/ubuntu/build_offline_bundle.sh ينسخ المشروع عبر rsync مع استبعاد Git/cache/logs فقط. Git/Docker ignores لا تحكم ذلك النسخ؛ يمكن أن يضم.env أو مفاتيح أو dumps أو userman-jobs موجودة في المشروع. لا تشغله للتوزيع قبل إصلاح التغليف بقائمة سماح وفحص محتوى. لم تنشأ حزمة هنا، ولا دليل على نشر حزمة سابقة بهذه المواد.
- deploy/license-server مكونات إصدار جزئية مقصود تتبعها. .dockerignore و COPY الانتقائي يستبعدانها من صورة المستأجر، ولا يضمنان ذلك في كل أداة نسخ أو تغليف خارجية.

## ما عولج ضمن نطاق التوثيق

- أزيل عرض الاعتمادات الافتراضية من README، وصُحح وصف ملفات أمثلة البيئة.
- استُبعدت بيانات storage ومنها userman-jobs، مع الحفاظ على المفتاح العام و.gitkeep. أضيفت قواعد المراجع الخاصة والاعتمادات والمفاتيح الخاصة إلى Git وسياق Web، واستبعادات للسياقين Core/L2TP.
- المرجع المحلي خارج Git وسياقات Docker المعروفة، بصلاحيات المستخدم و SYSTEM فقط. يحفظ إحالات اعتماد، ولا يحفظ محتوى مفتاح خاص أو dump عملاء. لم تُنقل إدارة VPS لحاوية عميل.

## الحدود والعمل المستقل

لم تُفحص بايتيًا كل طبقات الصور المنشورة، أو كامل Git history، أو الحزم القديمة لدى الأطراف. عدم العثور على حزمة في مجلد المصدر لا ينفي وجود نسخة خارج الجهاز. فحص Dockerfile والاستبعادات والبصمات أضيق من تدقيق كل طبقة.

المطلوب في مهمة منفصلة:

1. استبدال الافتراضات الحساسة الثابتة بتهيئة مناسبة، ثم تغيير الاعتمادات الفعلية التي تطابق المنشور ضمن تفويض تشغيلي.
2. إصلاح offline packaging وإضافة اختبارات تمنع نقل الخاص؛ ignore وحده لا يكفي للنسخ المباشر.
3. إذا ثبت سر خاص منشور سابقًا، حصر نطاق النشر ووضع خطة تدوير ومعالجة تاريخ وحزم مصرح بها. لا تعِد كتابة التاريخ أو تدوّر المفاتيح ضمن مهمة توثيق.
