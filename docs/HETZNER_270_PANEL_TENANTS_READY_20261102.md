## المعاينة وحدودها

اللوحة المؤقتة: `https://2.31.161.122`؛ شهادة ذاتية مؤقتة، وليست شهادة النشر النهائية. دخولها ببيانات لوحة control المنسوخة. عولج تمرير Origin لعنوان IP المحدد وحده دون تعطيل CSRF أو قبول أصل آخر.

المنظومتان عبر443 بأسماء المضيف، ومنافذ Web الداخلية loopback فقط. لمعاينة محلية فقط يمكن إضافة إلى Windows hosts:


عندها يوجّه الجهاز نفسه إلى الوجهة الجديدة الفارغة، بينما DNS العام لم يتغير. أصل HTTPS المؤقت يحمل SAN للأسماء الثلاثة وIP. التحقق المرحلي من origin محدود بـm/max1 وnonce محلي؛ ليس إثبات DNS عام. يزال وضع staging وتصدر شهادات معتمدة قبل التحويل النهائي.
