سُحبت الصور بالبصمة وتحققت Config وRootFS والتوقيع قبل التبديل. حُفظت نسخة معاملات من قاعدة max1 تشمل التريغرات والإجراءات، وتعريف Compose وحالة الحاويات ولقطة البيانات، وطابقت النسخة خارج المضيف SHA256 قبل الإيقاف. استُعملت معرفات الحاويات الدقيقة دون `compose up`. جُهز Web الجديد ومخطط الملكية الإضافي مع بقاء Core السابقة عاملة، ثم بدلت Core الخاصة بـmax1. بقيت الحاويتان السابقتان متوقفتين للرجوع، وثُبتت الصور في Compose. مدة مرحلة التبديل والتحقق 47.662 ثانية؛ لا تمثل قياسًا لانقطاع الإنترنت أو RADIUS عند المشتركين.

تعمل الحاويتان بحالة healthy وصفر إعادة تشغيل، ومثبتتان في تعريف التشغيل. أعاد فحص الربط من Web هوية Core الجديدة الصحيحة. توقيع Web ومفتاح الناشر وmanifest مطابقون للبناء المختبر، وملفات Core التشغيلية الأربعة مطابقة للمصدر المجمد. لا Traceback أو ModuleNotFoundError في سجلات الإقلاع المقاسة. صفحة الدخول العامة عبر HTTPS وصفحات الحزم والمشتركين وتفاصيل كرت وتفاصيل المشترك الموجود وملفا JavaScript أعادت 200.

بقي الترخيص والـlease فعالين. حزم الترخيص وبصمتا الجهاز والنسخة محفوظة؛ تغيرت فقط مواعيد heartbeat وتجديد lease والمؤشر الزمني الطبيعي. لم يجر تعديل ربط أو استبدال اعتماد أو تجاوز حارس.
