## لماذا لم يكتمل القبول؟

ظهرت انقطاعات ردHTTP ورفض لعمليات بسبب تعذر اتصال وسيطDocker المختبري، ثم تعذر DockerAPI نفسه. بلغ عدد أخطاء العمال المحفوظة10، يشمل أخطاء العينات والبروتوكول والطلبات؛ لا تعامل جميعها كعشرة عيوب منتج.

ثبت فقد الوصول بمسارات مستقلة: Dockerinspect/version أرجعا500 أو انتهت مهلتهما، وحتى اختبارAPI1.45 لم يستجب؛ WSL إلىdocker-desktop انتهى بخطأ اتصال؛ HTTPhealth/login انتهيا بمهلة، وقراءةSQL انتهت بخطأ2013 رغم قبول اتصالTCP. بقاءTCP مفتوحًا لا يثبت سلامة الخدمة. ليس لدينا دليل جذري يربط عطلDocker بالمحرك الجديد أو بتعديل معين، ولا إحصاء OOM نهائي للمضيف.

أوقف مشغل الحمل المضيف المملوك للجولة بعد ثبوت توقف العمال الماليين الأربعة. لم تُعد طلبات مالية غير مؤكدة. انتهت مهلة عامل الرصد المختبري عبر ملفه الخاص حتى يخرج عند عودة التنفيذ. لم نعد تشغيلDocker أوWSL أو نغير أي حاوية أخرى.
