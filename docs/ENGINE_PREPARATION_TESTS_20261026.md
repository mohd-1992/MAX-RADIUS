# اختبارات مسار تحديث تهيئة المحرك — 26 أكتوبر 2026

هذه لقطة اختبارات ما قبل التنفيذ. نُفذ المصدر لاحقًا بطلب الإنسان؛ انظر [الإصلاح المحلي والفحوص وحدود القبول](ENGINE_PREPARATION_FIX_20261026.md). تبقى نتائج القارئ القديم أدناه مرجعًا لضرورة التحديث المرحلي.

## الحكم

يمكن وصف وإيصال تحديث Web متوافق بلا ترحيل عبر عقد القارئ القديم، لكن **لا توجد بعد حزمة تهيئة منفذة ومختبرة لترقية المتحكم المستقل**. لا يجوز اعتبار إتمام Web دليلًا على تجهيز المحرك. نتيجة هذه الجولة تحدد موانع المسار الحالي؛ ليست قبولًا لإرسال إصلاح غير منفذ.

طلب الإنسان تنفيذ الاختبارات وتقريرها. مصدر النظام ومحركه لم يعدلا، ولم ينشأ إعلان حي أو عميل أو دومين أو صورة. استُعمل مركز اللوحة المعدل بمخزن SQLite اصطناعي جديد مع حجب الشبكة وsubprocess، وقارئ MAX الحالي الحقيقي import-safe فقط. اختبارات المنفذ تستخدم Docker مزيفًا وملفات مؤقتة داخل runtime Linux التطوير الموجود؛ لا تبديل خدمات أو SQL أعمال.

## ما يلزم تنفيذه قبل قبول تحديث التهيئة

1. تعريف حزمة جسر يستطيع المنفذ القديم تنفيذها، بلا تغييرات MAC أو SQL أعمال، وبصور وناشر ثابتين. استبعاد الميزات من البيان وحده لا يستبعدها من صورة Web2.6.6 الحالية.
2. تسليم تحكم محصور بالمنظومة نفسها إلى controller جديدة مع الحفاظ على التخزين والثقة وقفل المهمة؛ لا أوامر عامة أو صلاحية تحكم بخدمات أخرى.
3. إنهاء مهمة المنفذ القديم بإيصال، وإثبات أن الجديدة هي التي تجيب عبر socket وتعلن protocol2 فعلًا، وبقاء ذلك بعد إعادة تشغيل Web/controller. يتجنب التصميم إيقاف العامل الذي ما زال يسجل نتيجته.
4. رجوع خاص بالتهيئة إذا فشل تشغيل المنفذ الجديد، دون استعادة DB قديمة أو إعادة إرسال نفس الجولة المجهولة. يجب أن تبقى إمكانية القراءة والاسترداد حين ينقطع الرد بين تسليم المنفذين.
5. ربط الإتاحة اللاحقة بتحقق القدرات محليًا؛ القيم المبلغة للقناة ليست إقرار جهاز موثوقًا مستقلًا. لا توسع القناة لقبول SQL حر أو مستودعات غير معتمدة.

## ما بقي غير قابل للاختبار قبل التنفيذ

لا صورة تهيئة جديدة أو مسار handoff منفذ حتى الآن، لذلك لم يختبر تثبيتها الفعلي أو إعادة تشغيلها أو فقد الطاقة خلال تسليم التحكم. لا يمكن توليد نسبة نجاح أو شهادة رجوع لتلك الأجزاء من اختبارات الكود القديم. بعد التنفيذ يلزم اختبار الصور الفعلية في تركيب دومين وتركيب محلي معزولين، ثم التوقيع والترخيص وقفل الهوية والفشل وانقطاع المضيف. لا يستبدل ذلك بتجربة على عميل.

اختبارات SQL وFreeRADIUS الحقيقية السابقة أثبتت عمل المصادقة والمحاسبة بعد تهيئة المخطط، وأثبتت رجوعًا يضعف سياسة MAC في زوج2.6.5 المختبر؛ تبقى هذه قيودًا على تحديث الميزات، ولا تزال غير مصححة ضمن اختبارات التهيئة الحالية.
