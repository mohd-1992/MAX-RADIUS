1. مراجعة الحالة والإيصالات، ثم فحص المضيف والصور والحاويات وCompose وNAS والترخيص والتغطية قراءة فقط. لا تحديث تلقائي لمرجع NAS أو النسخة عند الاختلاف.

5. فشل محقق أو فوات مهلة التشغيل يُسلح رجوعًا واحدًا ضمن حواجز الهوية والخدمات المحمية. فقد رد Docker لا يجيز تكرارًا أعمى؛ تُراجع النتيجة الفعلية والـjournal أولًا.
