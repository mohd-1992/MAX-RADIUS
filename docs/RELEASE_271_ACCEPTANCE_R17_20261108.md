## حالات جديدة ناجحة دون إعادة عمليات المال والنسخ المقبولة

- إعدادات ونسخ مجدول وتعافٍ: تسع حالات؛ حفظ المنطقة الزمنية، رفض صورة شعار غير صالحة، مواعيد النسخ المعطلة، وعمليات scheduler حين يكون معطلًا، وحماية جلسة حديثة من تنظيف الجلسات الراكدة. إغلاق watchdog يبقى غير مؤكد وليس Stop فعليًا.
- سبع حالات إضافية لأزرار النسخ والتنبيهات والتصدير والخروج. رفع/تنزيل/حذف نسخة اصطناعية محتفظ بها يخص نسخة ملف جديدة فقط؛ لم تعد الاستعادة أو إنشاء النسخة المقبولة. تشغيل جدول النسخ كان لموعد مستقبلي، ثم عطل في finally ولم ينشئ نسخة تلقائية.
- أربع عشرة حالة لخرائط التغطية والأبراج ونقاط الوصول والأدوار وتصميم الكروت. رفع الخلفية يحفظ البايتات الأصلية؛ افتراض أداة الفحص بأن الخدمة تكبرها كان خاطئًا وصحح بقراءة الدليل دون إعادة الرفع.
- إحدى عشرة حالة للمدير والتحويل: التعديل وكلمة المرور، التعطيل وإعادة التفعيل، الحذف المنطقي وحماية المدير الأساسي والمدير ذي الرصيد، وإيداع/تحويل المحفظة ومنع التكرار والسحب الزائد. إنشاء ممثلي الاختبار تجهيز، لا يضاف كاختبار قبول جديد.
- ثماني حالات جديدة للبوابة والإعدادات: التسجيل الذاتي الصحيح والخاطئ، الدخول JSON مع CSRF، حفظ سرعة الدخول القادم، رفض كلمة مرور حالية خاطئة، تغييرها ومزامنة RADIUS وقبول الجديدة ورفض القديمة، خروج البوابة، وحفظ سياسة كروت الموزعين. لم تغير الجداول المالية.
- تمديد حساب موقوف مع بقاء الإيقاف، ثم دخول فعلي وإنهاء وحذف حساب اصطناعي مع حفظ UID والعدادات وسجلات المحاسبة. فصل الجلستين المتزامنتين والعودة بأجيال جديدة لهما إيصالان مستقلان.

## الانحرافات وحدود الأدلة

فشل اختبار r14 ذي الجلستين بعد وصول Stop لإحداهما وبقاء الأخرى. لم تحفظ أداة الفصل القديمة مرحلة الخطأ، فلا ينسب سبب مؤكد إلى الشبكة أو التوقيت. صححت قابلية التشخيص وعزل الفشل؛ محاولة الجلستين التالية نجحت. بعد تبديل r15 وجد عائق مستقل: سجل Hotspot لمضيف المختبر كان يحمل MAC حاوية Web السابقة. حُذف سجل مضيف الاختبار القديم وحده، مع بقاء bypass وعملاء الراوتر دون استهداف. التبديل التالي حافظ على MAC الخاص بمتحكم المختبر.

محاولة حقن فشل فوق فصل فعلي في r16 انتهت دون حفظ الملاحظات المؤقتة قبل assertion؛ لا تحسب اختبار حقن نقل فعلي ناجحًا. القراءة اللاحقة تثبت وصول Stop للجلسـتين، لكنها لا تستعيد الملاحظات المفقودة. عقد الفشل المترجم المنفصل نجح بنقل محاكى، ويصرح بهذا المستوى.

تكررت ست قراءات GET غير مغيرة للحالة عند انتقال دليل النماذج من r11 إلىr13؛ سجلت مرة واحدة في العد. لا تجمع سجلات المجموعات مع الحالات الفردية، ولا تعد تجهيز الحسابات إعادة قبول مالي. النيات الفاشلة محفوظة ولا تعاد مشغلاتها.

WireGuard والنقل الكامل لـL2TP/NAT وجهة الترخيص الإنتاجية لا تتحول إلى نجاح فعلي بمجرد قبول API. قبول PPP الأصلي في هذه الجولة استعمل PPPoE داخل Linux، مع NAT محاكى؛ يذكر هذا القيد صراحة. WhatsApp مستثنى. لا تشغيل لمراقبة العميل أو معاملات أو تغييرات إنتاج.
