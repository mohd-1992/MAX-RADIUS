جميع الصفوف أعلاه تخص صورة **Web**، بما فيها ملف `core/watchdog.py`. لم تتغير صورة FreeRADIUS أو تريغرات المحاسبة أو معادلات التسعير والخصم. للأتمتة جداولها وترحيلاتها المعتمدة في الخطة؛ هذا مختلف عن تغيير صورة DB.

حماية تغيير الباقة تعتمد على مرجع طلب صالح. نافذتا المشتركين والكروت أصبحتا ترسلانه تلقائيًا. بقي توافق عملاء API القديمة التي لا ترسله دون تغيير؛ لا توصف طلباتهم بأنها محمية بمرجع غير موجود.

## 4. أرقام الزمن والذاكرة قبل وبعد

هذه القياسات المحلية المحفوظة استعملت **نفس البيانات والموارد**. لم تُعد التجارب الناجحة لتوليد نسب جديدة للصورة r25؛ احتُفظ بأدلتها وتطابق ملفاتها. القيم مدوّرة.

- الزمن يخص تجهيز بيانات الخدمة، وليس زمن المتصفح كاملًا. لقطة Excel لا تشمل كتابة XLSX أو تنزيله.

- لم يعتمد تحسين RAM وقت الخمول؛ الوفر لم يتكرر بشكل مادي تحت الضوابط، فبقيت إدارة الذاكرة والخيوط كما كانت.
- لا تجمع نسب العمليات لإنتاج نسبة عامة للنظام.

| WireGuard | إنشاء وتعديل وحذف، وحفظ السجلات عند رفض الإزالة | MariaDB فعلي، وجسر Unix محاكى؛ لا يدعى اتصال VPN فعلي |
| الترخيص | ترخيص محلي موقّع ونبضة صحيحة وحفظ متسق | لا تفعيل ترخيص عميل لدى جهة الإنتاج الخارجية |
| المتصفح | مرجع الطلب يخرج في FormData من الصفحتين الفعليتين | طلبات الكتابة اعترضت؛ أثر المال اختبر عبر HTTP مستقل |
| النسخ والصيانة | نسخة من زر الواجهة، وأرشفة UID اصطناعي وتحسين جداول مع حفظ القيم | الإرسال معطل في الاختبارات الجديدة |

الحمل المترجم المحفوظ أنجز **1397 قراءة خلال 35.101 ث** بالتزامن مع 20 قبول مصادقة و60 استجابة محاسبة بلا إخفاق. بلغت RSS العملية 59.71 MiB ثم 57.66 MiB بعد 10 ثوانٍ خمول. مرسل UDP اصطناعي؛ ليس 20 جهاز RouterOS.

في اختبار القفل المحفوظ اكتملت النسخة في **46.194 ث / 34.85 MiB** مع حركة RADIUS، ورفض PDF أثناء القفل، ثم صدر **936 كرتًا / 24 صفحة في 13.434 ث** مع تطابق بصمة النص. لا توجد ذروة cgroup محفوظة للعملية المركبة، ولم تخمن لها قيمة.

لم تُعد الاختبارات المقبولة لمجرد نقص رابط في المصفوفة. حُسمت افتراضات بعض أدوات الفحص بالقراءة فقط، دون إعادة عمليات الاستيراد والحذف والنبضة. خطأ اسم جدول في أداة النسخ استدعى تهيئة المخطط داخل المختبر قبل أي طلب نسخ؛ طابقت بصمات المال قبله وبعده.

## 7. إغلاق المتبقي وما يسبق النشر

مكون المضيف لمحاكي RADIUS المستضاف **منفصل واختياري وموقّع ومجهز فقط**. لم يركب على هدف. صورة Web وحدها لا ترقيه، ولا تضمن أن غلاف SQL قديمًا يحفظ التوقيت؛ مطابقة أغلفة التشغيل شرط نشر مستقل.

لم يُحدث دومين أو عميل، ولم تُرسل رسائل جديدة، ولم تُستأنف المراقبة. WhatsApp مستثنى، وتجارب RAM غير المعتمدة لم تدخل الصورة.
