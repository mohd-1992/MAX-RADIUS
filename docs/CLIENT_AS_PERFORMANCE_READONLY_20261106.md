- قياس استعلام الحصة الخاص بالمراقب الخلفي على ثلاثة حسابات نشطة دون إرجاع بياناتها؛ احتفظت الأدلة بزمن وخطط وصول منزوعة شروط الحسابات. هذا SELECT فقط، وليس تشغيل دورة المراقب أو الفصل أو التسوية.
- خمسة مسارات HTTP، ثلاثة طلبات GET متتابعة لكل مسار من loopback داخل Web، واستجابة الجسم تُتلف بعد حساب الحجم. استخدمت جلسة إدارية مؤقتة موقعة داخل الذاكرة بالمفتاح الموجود، دون إنشاء حساب أو تغيير كلمة مرور أو نسخ المفتاح. أداة القياس الأولى استعملت اسم Cookie غير المطابق فأعادت 302/401؛ حُفظت كرفض أداة ولا تدخل نتائج الأداء. الاسم الصحيح `max_radius_session` أعطى 200 في جميع القياسات المعتمدة.
- لم تُقَس دورة الرسم في متصفح المستخدم أو زمن WAN أو تزامن عدة مديرين أو جميع الفلاتر/الفرز. أزمنة GET أدناه ليست دليلًا على تحمل الضغط. لم تُفتح صفحات الكروت الحية آليًا لأنها تستدعي `sync_voucher_activations` وقد تكتب تفعيلات؛ راجعت مساراتها في المصدر فقط. لا مصادقة RADIUS اصطناعية أو معاملات مالية أو تصدير/نسخ تجريبي.
