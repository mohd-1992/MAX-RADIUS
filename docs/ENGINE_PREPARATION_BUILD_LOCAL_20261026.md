## الفحوص المقاسة

في التركيب المحلي المعزول نجح انتقال2.6.5 إلى Web الجسر مع بقاء المتحكم القديم، ثم شغّل العامل المجمّع الجديد تسليم المتحكم وحقق protocol2 عبر Unix socket وختم الناشر. نجحت إعادة تشغيل Web والمتحكم وفشل تحقق المرشح ثم الرجوع. لا كود مصدر مربوط داخل /app؛ ملفات المختبر فقط خارج مسارات التطبيق الموقعة. العامل والمتحكم في الجولة المعزولة الأخيرة يستخدمان rootfs للقراءة فقط وتخزينًا خاصًا قابلًا للكتابة.

المصادقة وStart/Interim/Stop تمر عبر radclient وFreeRADIUS وMariaDB فعليين. ثبتت جلسة واحدة مغلقة في SQL بعد Stop، بعدادات إدخال4294967796 وإخراج8589935592، والرصيد17.25 محفوظ. قورنت checkpoints قبل التبديل وبعد الرجوع، ولم تستعد DB أثناء الرجوع. ثبتت هوية Core/DB ووقت تشغيلهما في الجولة المعزولة المصححة.

اختُبر فشل تحقق المتحكم بعد بدء مرشح فعلي، وضياع رد إنشاء Docker بعد الإنشاء الفعلي: رجوع المتحكم السابق مع فحص المقبس والختم، وإنشاء واحد فقط، مع recovery_required بدل إعلان اكتمال التهيئة. هذه حالات مستقلة عن نجاح التحديث العادي.

نجح المسار نفسه في تركيب دومين معزول على Docker المحلي، بلا DNS أو اتصال دومين خارجي. الجولة المصححة اجتازت22فحص حزمة بين التركيبين، مع جلسة مغلقة واحدة وعدادات64بت ورصيد محفوظ في كل قاعدة، وثبات Core/DB. اختبارات فشل المتحكم وضياع رد الإنشاء مثبتة بإيصالات مستقلة؛ لم تُعد في جولة قياس ثبات Core المصححة.

## تعثرات تجهيز المختبر التي فُصلت عن المنتج

- نفدت مجمعات شبكات Docker الافتراضية؛ اختيرت شبكات داخلية صريحة غير متداخلة، بلا منفذ منشور أو شبكة خارجية.
- حزمة الترخيص الاصطناعية لا تحمل توقيع ناشر؛ صفحة الدخول تبطل leaseها كما ينبغي. جُهز lease SQL اصطناعي صريح قبل حزم RADIUS، دون تعطيل حارس في المصدر أو تغيير مرجع الثقة. لا يُدعى بهذا قبول ترخيص ناشر حقيقي.
- مصدر النسخ القديم يقرأ إعدادات الإشعارات حتى عند dispatch_notifications=False، فيهيئ wisp_notification_channels وwisp_notification_logs:21عمودًا مضافة قبل أول تبديل، وصفر عمود سابق متغير أو محذوف. فُصلت هذه التهيئة عن بصمة ما قبل التبديل؛ لا إشعار أُرسل.
- صورة Core القديمة تورّث autoheal=true؛ تدخل الحارس المحلي في fixture أولى. استُبعدت تلك الجولة من إثبات ثبات Core، وضُبطت الحاويات الجديدة autoheal=false وفُصلت healthchecks الاختبارية عن فحوص RADIUS الفعلية، دون تعديل الحارس القائم. اجتازت الجولة المحلية المصححة شرط ثبات Core/DB.
