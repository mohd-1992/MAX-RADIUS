محرك FreeRADIUS 3.0 المتطور

معالجة فورية لآلاف طلبات المصادقة (Auth & Accounting) في الثانية الواحدة مع دعم كامل لـ Hotspot و PPPoE و IPoE بدون أي تأخير.

مستورد User Manager v6 فائق الذكاء

انقل شبكتك بالكامل في ثوانٍ معدودة. يدعم استيراد سكربتات `.rsc` وملفات النسخ الاحتياطي مع استخراج المستخدمين، الكروت، الجلسات، والبروفايلات تلقائياً وبأمان تام.

استوديو توليد وطباعة الكروت

توليد ملايين الكروت بضغطة زر مع قوالب طباعة مخصصة عالية الجودة، باركود و QR Code، وتوزيع مرن للوكلاء ونقاط البيع بنظام المحافظ المالية.

نفق VPN مشفر مدمج (L2TP/IPSec)

اربط جميع راوترات MikroTik البعيدة بالسيرفر السحابي بأمان فائق وتشفير عسكري حتى بدون وجود Real IP ثابت في موقع الشبكة.

معمارية Docker ذاتية التعافي

مبني على 5 حاويات Docker معزولة تماماً مع نظام مراقبة مستمر (Auto-Heal) يعيد تشغيل أي خدمة تتعثر فورياً بدون انقطاع للخدمة.

نظام محاسبي ومحافظ وكلاء (POS)

إدارة شاملة للمبيعات، حسابات الموزعين، الشحن بالرصيد، تتبع الإيرادات، وتقارير أرباح مفصلة تدعم الفواتير الإلكترونية وضريبة القيمة المضافة.

الهيكلية السحابية الحديثة

معمارية متجانسة مبنية على
5 حاويات Microservices مستقلة

تم التخلي عن الأنظمة المترابطة المعقدة التي تنهار بالكامل عند تعطل جزء بسيط. في MAX RADIUS، كل طبقة تعمل داخل بيئة معزولة وتتواصل عبر شبكة داخلية آمنة.

1. max_radius_db (قاعدة البيانات الأساسية)

تخزين فائق السرعة مع صيانة تلقائية، إلغاء تجزئة الجداول، ونسخ احتياطي مجدول.

2. max_radius_core (محرك RADIUS والمزامنة)

FreeRADIUS 3.0 عالي الكفاءة لمعالجة الجلسات والاتصال المباشر براوترات الشبكة.

3. max_radius_web (لوحة القيادة والواجهة الإدارية)

واجهة حديثة سريعة الاستجابة، تقارير فورية، وإدارة شاملة للمشتركين والبطاقات.

4. max_radius_l2tp & max_radius_autoheal

تأمين اتصالات VPN الخاصة بالميكروتك مع مراقبة ومداواة ذاتية فورية 24/7.

docker-compose.yml All Services Healthy 
# MAX RADIUS Multi-Container Architecture
services:
  max_radius_db:
    image: mariadb:10.11
    restart: unless-stopped

  max_radius_core:
    image: mohd777/max-radius-core:latest
    ports: ["1812:1812/udp", "1813:1813/udp"]

  max_radius_web:
    image: mohd777/max-radius-web:latest
    ports: ["80:80", "443:443"]

  max_radius_l2tp:
    image: teddysun/l2tp
    cap_add: [NET_ADMIN]

  max_radius_autoheal:
    image: willfarrell/autoheal

هل يمكنني نقل بيانات المشتركين والكروت من يوزر مانجر القديم؟

نعم بكل تأكيد! يحتوي MAX RADIUS 2.0 على أداة استيراد معزولة بالكامل تقوم بقراءة ملفات سكربتات التصدير (`.rsc`) من MikroTik User Manager v6 وتحويل كل المستخدمين، الباقات، وجلسات النشاط بدقة 100%.

هل أحتاج إلى عنوان IP ثابت (Static Real IP) في موقع الشبكة؟

لا، لا تحتاج إلى IP ثابت على راوترات المايكروتك! النظام يضم سيرفر L2TP/IPSec VPN مدمجاً يسمح للراوترات بالاتصال بالسيرفر السحابي بأمان كامل عبر أي اتصال إنترنت متاح (4G, DSL, أو ألياف).
