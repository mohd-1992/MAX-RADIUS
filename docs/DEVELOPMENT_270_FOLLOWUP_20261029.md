الفصل لا يغير الرصيد أو الباقة أو تفعيل الحساب، ولا يغلق SQL Accounting أو يختلق Stop أو عدادات. هوية الجلسة وNAS ووقت البدء وإثبات RADIUS مطلوبة قبل الطرد. تعذر الهوية/uptime يظهر غير مؤكد. بعد توقف عامل في منتصف محاولة، التحقق فقط دون إعادة إرسال عمياء. الاستعادة/الترحيل يبطلان الجيل المحلي، وجلسات Backup-Restored-Closed لا تستهدف NAS.

سجل المهام في STORAGE_DIR/session-operations بصلاحيات محدودة وكتابة ذرية؛ ملفات المستخدمين/النسخ الاحتياطية لا تشمل هذا السجل التشغيلي. حد 1000 جلسة للقطة و200 مهمة معلقة، مهلة 180 ثانية، إيصالات مكتملة سبعة أيام، وعدد ثابت من ملفات الأقفال. كل عمال Web للدومين يشتركون في STORAGE_DIR وهوية DB_HOST والمخطط. عند فشل جدولة تطبيق MAC تبقى السياسة محفوظة وتظهر رسالة عدم التأكد؛ إعادة حفظ الملاحظة وحدها ليست إعادة تطبيق للجلسات. يمكن متابعة المهمة الموجودة، أو فصل يدوي مقصود بعد زوال المانع؛ لا إعادة فصل تلقائية غير محدودة.

قفل دورة الحساب أصبح يشمل اسم schema بالإضافة لاسم الحساب؛ يحمي منظومات المحرك المشترك من تعارض أسماء المستخدمين المتشابهة. يجب تبديل جميع عمال Web للمنظومة معًا؛ المزج بين عمال قديمة وجديدة لا يوفر قفل دورة موحدًا. لم يتغير شرط التسوية المالية للتجديد/تغيير العقد.
