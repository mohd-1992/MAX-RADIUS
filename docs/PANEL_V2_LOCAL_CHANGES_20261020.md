# تغييرات المصدر لقبول لوحة V2 محليًا — 20 أكتوبر 2026

هذه رقعة مصدر محلية لمشروع اللوحة المعتمد، وليست نشرًا أو تغييرًا على خادم أو عميل. أدلة Docker موجودة في مشروع max_saas_panel_v2_local داخل reports بتاريخ 20 أكتوبر؛ لا تفتح أي مرجع وصول أو جولة مالية مغلقة من أجل قراءتها.

## حراسة الميزات

core/license_feature_policy.py يعرف مفاتيح العقد الـ23 ومعاني الغياب والاعتماديات، وweb/license_features.py يطبق حد HTTP. أضيفت حدود الخدمة والعامل إلى المالكين الموجودين، مع تقاطع الصلاحيات والملكية في web/access_policy.py، وإخفاء العلامة المخصصة دون حذفها عند تعطيل white_label. العامل يعيد قراءة الحالة، ولا يحول غياب ميزة قديمة إلى false.

القبول الأصلي في FEATURE_GUARDS_ACCEPTANCE_20261020 اختبر الغياب القديم والتعطيل والتمكين وإعادة الغياب: 141 رفض HTTP و9 خدمات و5 عمال مع ثبات البيانات المالية. تبقى إيصالات التنفيذ السابق قابلة للقراءة بعد تعطيل الميزة، ولا تعطل التسوية والمحاسبة وإنفاذ الترخيص الأساسي. api_access لا يملك API مستقلًا في المرجع؛ لا يحجب AJAX الداخلي ولا ينشئ API جديدًا. فحوص المصدر المختارة موثقة في تقرير اللوحة.

## النسخ والاستعادة

core/backup_archive_policy.py يفحص الأرشيف قبل الكتابة: المسارات الخارجة والروابط والأعضاء المكررة والملفات الخاصة والحمولة المفقودة مرفوضة. services/backup_service.py يبقي SQL/uploads الأصلي، ويبث الملفات، ويمنع حمولة SQLite فقط على MySQL. لا يشمل الأرشيف كل القرص، واستعادة ملفات الرفع إضافية، ولا تعد نتيجة HTTP قبولًا لاكتمال إصلاح المخطط والمشغلات.

نجحت ثلاثة فحوص في tests/test_backup_archive_policy.py، وقبول Docker جديد من API اللوحة إلى create_backup/restore_backup: تنزيل وبصمة واستعادة إعداد وملف وصلاحية ترخيص ونسخة استرداد وحد محلي بخمس نسخ ورفض حالة مالية أحدث. NATIVE_BACKUP_ACCEPTANCE_20261020 يثبت الصورة وبصمات المصدر؛ ثلاث حاويات أوقفت و560 سابقة ثابتة، ولا منافذ أو اتصال خارجي.

## watchdog

نقل فحص factory_reset_active داخل حد معالجة أخطاء run_watchdog_cycle. خطأ قاعدة البيانات المؤقت يعاد كخطأ دورة بدل أن يخرج ويوقف العامل. فحص tests/test_watchdog_failure_boundary.py ناجح دون استيراد التطبيق أو الاتصال بقاعدة. قبول المكونات الموقعة اختبر دورة watchdog الأصلية وRADIUS وDB والتراجع، مع انتظار نتيجة حديثة وصحة المجموعة النهائية. لا مخطط محاسبة جديد أو تعديل سياسة مالية.

كل الاختبارات المعنية معزولة. لا يفوض هذا التوثيق إعادة المحاسبة أو seed أو استعادة DB قديمة أو نشر الرقعة. التغييرات السابقة غير المتعلقة باللوحة محفوظة، والحالة هنا لقطة مؤرخة.
