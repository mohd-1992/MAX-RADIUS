# معاينة هوية الناشر وحماية ملفات العرض

هذه معاينة مصرح بها على LAB_UBUNTU فقط، وليست إصدارًا عامًا أو تحديثًا للعميل. حالة النشر المقاسة والتراجع في HANDOFF؛ لا يكفي وجود المصدر لإثبات النشر.

## فصل هوية المنتج عن الشبكة

`core/product_identity.py` هو المصدر الخاص بالمنتج واسم مالك الحقوق الظاهر ورقم المطور `967777366226` وروابطه. القيم بيانات إصدار مجمعة ومشمولة بتوقيع runtime؛ لا تؤخذ من قاعدة المستأجر أو APP_NAME في البيئة. لا يمثل اسم المنتج إثباتًا لاسم شخص أو كيان قانوني لم يحدده المالك.

تبقى network_name/network_logo/support_phone/support_email/portal_whatsapp/portal_support_phone لصاحب الشبكة. لا تحول أزرار دعم المشترك إلى المطور. صفحة الترخيص الحالية تعرض حقوق المنتج والتواصل واتساب/اتصال/الموقع؛ الرقم لا يظهر كنص مستقل في بطاقة الحقوق، ويبقى في روابط التواصل وطلب الترخيص/الترقية؛ لا صفحة «حول» جديدة ولا إرسال تلقائي لبصمة أو رسالة.

القالب العام يستخدم وصف system_title بجوار الاسم الثابت، مع إزالة اسم المنتج المكرر منه. أزيلت لاحقات الاسم المكررة من عناوين الصفحات؛ سند المحفظة وكشف المبيعات يستخدمان هوية المنتج والإصدار الحالي بدل 2.0 الثابت. قالب الترخيص المستقل موجود في الحزمة، لكن ربطه بمسار حي غير مثبت.

## التغليف والتحقق

`packaging/embed_templates.py` يولد web._embedded_templates من قوالب المصدر بترميز مضغوط؛ يجمعه Cython ثم يحذف قوالب HTML النصية من filesystem صورة الإصدار. Flask يستعمل DictLoader من الوحدة المجمعة، ولا يستعمل filesystem override في الإصدار. التطوير من المصدر يستعمل القوالب العادية عند غياب الوحدة المولدة.

هذا تجميع وتضمين، وليس تشفيرًا يستحيل فكه. HTML النهائي يصل للمتصفح. البناء الخاص للمعاينة يصدر filesystem نهائيًا من مرحلة scratch كيلا تبقى قوالب الأصل النصية في طبقات صورة التوزيع؛ لا تتضمن الصورة النهائية مرحلة المترجم. المكتبات المفتوحة المصدر وإشعاراتها ليست ملكية خاصة يُراد إخفاؤها.

`packaging/minify_assets.py` يصغر JS/CSS الخاصة بالمشروع فقط، دون إعادة تسمية الرموز أو تغيير ملفات vendor أو إزالة إشعاراتها. تعمدت المعاينة تجنب التشويش العدواني الذي قد يغير سلوك JavaScript.

`core/runtime_integrity.py` يتحقق محليًا من توقيع البيان وبصمات الملفات في عامل خفيف كل خمس دقائق. الإخفاق تنبيه فقط؛ لا SQL أو شبكة أو إصلاح تلقائي أو خروج للعملية أو تغيير ترخيص/محاسبة. تحقق بدء التشغيل الموجود مسبقًا يبقى مستقلًا، وقد يرفض Web عند فساد ملفات الإصدار؛ ليس هذا وعدًا باستمرار Web بعد أي عبث في أي ملف.

## الملفات القابلة للكتابة

حاوية Web للمعاينة تستخدم read_only rootfs مع نفس mounts البيانات والرفع ومقبس Docker السابق، وtmpfs لـ/tmp و/run. تحدد XDG_CONFIG_HOME وXDG_CACHE_HOME داخل /tmp لتوافق Chromium. إبقاء مقبس Docker مقصود لحفظ وظائف الإدارة الحالية؛ لم تُدّع حماية من root أو إلغاء صلاحيات المضيف.

تحتاج مسارات النسخ المخصصة خارج mounts الحالية مراجعة/ربطًا صريحًا قبل استخدامها مع rootfs المقفول. لا تُجرب الاستعادة أو إعادة المصنع على بيانات موجودة لمجرد فحص الواجهة. المصدر وملفات ضبط FreeRADIUS/SQL ليست كلها سرية أو مشفرة.
