### ملاحظة محاسبية لم تُغلق

أثناء تجهيز PPP لأول مرة ظهر لسجل Hotspot محفوظ سبب `NAS-Reboot` مع بقاء جلسته على NAS. استعلام Accounting-On/Off الحالي يغلق سجلات NAS جماعيًا؛ لم تُحفظ الحزمة الأولى لإثبات الحدث الذي أنشأ هذا الأثر. تجربة لاحقة بتعطيل **خادم PPP الاختباري فقط** وإعادته لم تكرر الأثر: بقي SQL مفتوحًا وHotspot متصلًا. لذلك لا يُنسب السبب الجذري بثقة إلى تشغيل الخدمة أو الإصلاح الجديد، ولا تعتبر هذه التجربة قبولًا شاملًا للتعايش عند تهيئة RADIUS/PPP لأول مرة.

أُغلقت الجلسة لاحقًا بأمر NAS فعلي ووصل Stop، ثم نجحت جلسة جديدة ومسار HTTP الكامل. تحفظ الأدلة الحالة السابقة واللاحقة؛ لا يطمس نجاح التنظيف الملاحظة. يلزم جولة جديدة مخصصة تلتقط Accounting-On/Off منذ إنشاء RADIUS/خدمةPPP، وتميز بدء الخدمة عن إعادة تشغيل الراوتر، قبل تغيير استعلامات Core أو اعتماد هذا البند.
