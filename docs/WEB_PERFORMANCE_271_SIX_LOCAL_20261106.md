## منهج المقارنة

- نفس اللقطة المحلية الموجودة:57,553كرتًا،344,153جلسة،28,289سجل بيع. لم تُحمّل نسخة جديدة. نُسخ volume الأصلي للقراءة فقط إلى مختبر مستقل.
- MariaDB10.11 بحد2CPU و1792MiB وbuffer512MiB؛ عامل قياس Web بحد2CPU و1GiB. شبكة داخلية بلا منافذ أو Docker socket. حساب التطبيق المقاس SELECT/SHOW VIEW فقط؛ لا تشغيل Flask أو عمال التطبيق أو أي عملية مالية/CoA/NAS.
- المصدر السابق حُفظ قبل التعديل، والمصدران استعملا نفس الصورة والبيانات والموارد. ثلاث محاولات لكل طرف، والجدول يعرض **الوسيط**. تسع مقارنات أساسية =54تشغيلًا صحيحًا. بارد/دافئ يخص كاش الخيارات، وليس تفريغ buffer DB أو كاش القرص. لم تُصفّر ذاكرة MariaDB بين الطلبات.
- الزمن وCPU Web لتهيئة استجابة الخدمة/بيانات الصفحة قبل توليد HTML أو نقلHTTP. CPU DB فرق `cpu.stat` للمختبر أثناء العملية؛ يشمل خيوط DB وكلفة أخذ العينة الصغيرة، وليس نسبة CPU لحظية. RAM Web أعلى RSS للعملية المستقلة، بما فيها تحميل الوحدات وأداة البصمة؛ ليست RAM ثابتة لخادم إنتاج كامل.
