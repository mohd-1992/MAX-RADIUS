# صفحات الكروت والحزم

مرجع التنفيذ: `web/routes/vouchers.py`، `services/voucher_service.py`، `services/quick_action_service.py`، `services/quota_service.py`، `services/card_design_service.py`.

- صلاحيات العرض والتوليد والإجراءات والحذف والطباعة منفصلة وفق RBAC الموجود. الطلبات المتغيرة تتطلب CSRF؛ التصاميم والطباعة تخضعان لصلاحية الطباعة.
- إنشاء الحزمة والكروت وخصم محفظة الموزع والفاتورة وRADIUS والتدقيق ضمن معاملة واحدة؛ يُقفل سجل المحفظة قبل الخصم. فشل خطوة يرجع المعاملة كلها. تعاد محاولة الاسم العشوائي المتصادم ضمن حد معلوم.
- تعديل كلمة المرور والماك ومزامنة RADIUS والتدقيق ضمن معاملة واحدة. تغيير اسم الكرت المستخدم ممنوع لحماية تاريخ المحاسبة؛ الاسم غير المستخدم يراجع مقابل الكروت والمشتركين. حقول الحالة والانتهاء في الملف ليست مسارًا لتغيير العقد.
- تعديل الباقة يستعمل مسار تغيير الباقة والتسوية القائم. إضافة الأيام والبيانات تستعمل `action_adjust_entitlement` بمعاملة واحدة، وتحفظ الإيقاف اليدوي واللقطة وبداية الدورة. البيانات الموجبة والسالبة تعدل `extra_quota_mb`؛ الصفر وحده مرفوض. الكرت المستهلك للشحن لا يعاد استخدامه.
- فك الإيقاف يستخدم سياسة دورة الحساب والترخيص؛ يعيد الكرت إلى نشط أو منتهي حسب كل الحدود، دون تجديد أو رصيد جديد. تعذر محاسبة الدورة يمنع التفعيل.
- قائمة الكروت تقرأ محاسبة الدورة وخطوط الأساس جماعيًا، والفحص يستخدم المحرك الرسمي. عند تعذر المحاسبة تظهر غير متاحة؛ الحصة الأصلية صفر تبقى غير محدودة. العدادات والصفوف والتفاصيل تستخدم نافذة الاتصال نفسها، خمس دقائق بتوقيت التخزين.
- فصل الكرت يستدعي عملية الفصل المشتركة بهوية voucher. قبول الطلب لا يثبت Stop النهائي؛ لا تغيير لمحرك CoA أو التسوية في هذه الإصلاحات.
- العمليات الجماعية تتحقق من IDs وتزيل التكرار وتعرض الناجح والفاشل والنتيجة الجزئية؛ صفر نجاح لا يعرض نجاحًا. إسناد الموزع للحزمة وكروتها ذري.
- الأسماء في معالجات JavaScript تمر عبر JSON وهروب HTML؛ معاينة اسم الحزمة تستخدم textContent. الطباعة تحترم قيم snapshot الصفرية والصلاحية غير المحدودة، ورابط QR يرمز بيانات الدخول ويصل إلى JavaScript دون تحويل & إلى &amp;.
- حفظ التصميم يقرأ config قبل اختيار الخلفية. فحص الكرت يدعم q وcode؛ الكرت الموقوف يعرض تنشيط الحساب بأيقونة مناسبة.

السرعة المعتمدة هي سرعة العقد/الباقة وفق المزامنة القائمة. طلب المستخدم بتاريخ 11 أكتوبر 2026 أكد التخلي عن فكرة اختيار السرعة من لوحة المشترك؛ لا أضيف استثناءً جديدًا لحفظها. المسار القديم `/user/api/change-speed` ما زال موجودًا في المصدر، ولم يحذف ضمن إصلاحات صفحات الإدارة هذه.

## التحقق وحدوده

`python -m unittest discover -s tests -p test_voucher_pages.py -v` يشغل 32 حالة على SQLite وFlask وقوالب حقيقية وفحص JavaScript عبر Node، دون استيراد التطبيق أو تشغيل عماله. شملت أعطال الفاتورة وRADIUS، رفض الصلاحيات وCSRF، حفظ الإيقاف والعقد، محاسبة baseline، فك الإيقاف والعمليات الجماعية والطباعة والتصاميم.

عرضت تسع صفحات على خادم fixture معزول؛ فُحص زر التنشيط ومعاينة الطباعة والعرض 390px والثيمان. هذه النتائج لا تثبت MariaDB متزامنة أو مصادقة NAS أو Stop أو PDF مطبوعًا فعليًا، ولا تثبت نسخة ماكس المنشورة.

اسم الحزمة التلقائي للإصدارات الجديدة: اسم الباقة — العدد كرت — اسم مستخدم الموزع إن وجد — #معرف الحزمة. المعرف مأخوذ بعد INSERT ويحدث الاسم في المعاملة نفسها، وليس تسلسلًا تخمينيًا. الإصدار السريع يستخدم الصيغة نفسها. الاسم المخصص محفوظ؛ لا إعادة تسمية للحزم القديمة ولا تغيير batch_number الفني.
