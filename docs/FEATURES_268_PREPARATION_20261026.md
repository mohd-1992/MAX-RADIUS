# مرشح الميزات 2.6.8 — تحضير محلي غير مؤهل للإرسال

طلب الإنسان إتاحة تحديث الميزات لسيرفر التجربة فقط، وأكد تضمين الماكات مع جميع ميزات الصفحات والتقارير والشعار والجلسات. جُمّد المصدر الحالي في سياق مستقل295ملفًا، مع خمسة ملفاتCore، وحُوّل رقم المرشح فقط إلى2.6.8 دون تغيير رقم التطوير المحلي. بُنيت Web8e85540a9532 وCorebc4d46441080 محليًا. **لم تُرفع الصور، ولم يُنشأ إعلان أو إشعار ولم يُغيّر سيرفر التجربة.**

## الفحوص المنجزة

نجحت تسع مجموعات مصدر معزولة، وختم الصورة المجمعة وتحميل وحدات الميزات والقوالب الـ80 والأصول الثابتة وصفحة الدخول. نجحت ترقية قاعدة MariaDB اصطناعية من مصدر2.6.7 من64 إلى73جدولًا وتكرار التهيئة. حقول عشر مجموعات بيانات أعمال محفوظة؛ التغيير الوحيد المسموح في المقارنةNULLglobal_seq_idإلىرقم مثبت فيwisp_global_sequence. اختبارات الماكات تحفظ القيد السابق ولا تستنتجه من المرور.

نجح Core الحقيقي في قبول الماك الأول والثاني المسموحين ورفض عنوانين غير مسموحين، مع Start/Interim/Stopحقيقية عبرradclientوصفSQLمغلق واحد بعدادات64بت:4294967996/8589935492. الترخيصSQLاصطناعي صريح؛ لا قبول ناشر أوNASحي. فشل تجهيز fixture أولى لتركيبtestsعلىمجلدقراءةفقط، ثمصححالمجلددونتغييرالمنتج؛ وفشل leaseاصطناعي بسبب مراجع الترخيص ثمجُددت الfixtureقبلحزمRADIUS. الفحوص النهائية مثبتة بإيصالات مستقلة.
