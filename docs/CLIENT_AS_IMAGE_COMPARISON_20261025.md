## فروق Web

ضمن نطاق الملفات المجرودة، بقي 85 ملفًا مطابقًا، وتغيرت بصمات 68 ملفًا، وأضيف 23 ملفًا. اختلاف بصمة وحدة مترجمة لا يثبت وحده تغيرًا دلاليًا مستقلًا فيها. تشمل النشرة الجديدة:

- تعديل المشترك والكرت، وإيصالات العمليات وسجل التعديل، وملكية التاريخ بعد تغيير الاسم.
- تصحيح فاتورة البوابة وربط Core الخاص بالتسوية، وتحديث الصلاحيات والإعدادات والترحيل ومركز التحديث.
- مثبت mysql_bootstrap وحماية استعادة الأرشيف.
- تضمين القوالب الـ72 داخل وحدة مترجمة؛ غياب HTML المنفصلة ليس حذفًا للصفحات.

مفتاح التوقيع العام وأداة التحقق متطابقان بالبايت. هذا لا يثبت قبول ترخيص العميل وlease على المرشح. مجلدات العميل المربوطة إلى Web تخص storage وuploads وDocker socket؛ لا يوجد ربط مصدر يتجاوز وحدات التطبيق ضمن هذا الجرد. تغييرات طبقة Web المرئية تخص مجلد الرفع.

## فرق Core الحرج

من 250 ملفًا مجرودًا، تطابق 248 ملفًا مباشرة. ملف license-capacity-postauth.conf متطابق بعد تجاهل نهاية الملف. الفرق الدلالي في queries.conf هو **11 استبدالًا من radacct a إلى radacct_owned a**، ولا توجد فروق نصية أخرى بعد توحيد نهاية الملف. سياسة max-accounting-identity مطابقة بالبايت، فتظل معالجة ثبات هوية الجلسة محفوظة.

قراءة information_schema في قاعدة Web الفعلية أثبتت وجود radacct وwisp_subscribers وwisp_vouchers، وغياب عروض owned وجداول الأسماء وإيصالات التعديل الأربعة وأعمدة الملكية المطلوبة.

المثبت الجديد يضيف جداول وأعمدة وفهارس وعروضًا وتريغر ملكية. **يمنع تفعيل Core الجديدة قبل اكتمال هذه الاعتماديات والتحقق منها.** إنشاء الفهارس وALTER قد ينتظر أقفال metadata؛ يلزم قياس أثره على نسخة حديثة ممثلة، واختبار رجوع متوافق مع أحدث المحاسبة.

Core الحالية دون mounts؛ إعدادات NAS وSQL الفعلية داخل طبقة الحاوية القابلة للكتابة، وبعضها مولد وقت التشغيل. تحفظ إعدادات الهدف والحاوية الأصلية، دون نسخ queries.conf القديم فوق الجديد أو نقل اعتمادات المختبر.

## تصحيحات العميل الخاصة

- **Telegram والنسخ:** الوحدة المترجمة في المرشح أعادت حد 45,000,000 بايت، و256 جزءًا، وسقف 5GiB. ظهر ثابت card_backgrounds في خدمة النسخ المترجمة، والمصدر الموثق يستثني الخلفيات. هذا يدعم حفظ السياسة، لكنه ليس اختبار إنشاء نسخة وإرسالها من العميل؛ لم ترسل رسالة أو نسخة. الحد 45,000,000 بايت وليس 45MiB.
- **هوية المحاسبة:** السياسة الحالية والجديدة متطابقتان؛ قراءة ملكية التاريخ الجديدة تحتاج المخطط المذكور.
- **حادثة الساعة:** إصلاح التواريخ أثر بيانات قديم لا يعاد تشغيله. وقاية المضيف عند الإقلاع اختيارية ومنفصلة، وليست حاوية لازمة لنشرة الميزات.
