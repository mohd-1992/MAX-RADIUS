name: max-project-onboarding
description: Identify MAX RADIUS feature owners and development entrypoints for a new task or developer.
---

Read [PROJECT_MAP](../../../docs/PROJECT_MAP.md) and only the domain document matching the task. Confirm Git root and distinguish tenant code from the external domain panel. Use `python scripts/project_tools.py find <symbol-or-route>`; regenerate the static index if source changed. Read CURRENT_STATE only for recorded status, not live health. Trace the actual handler/service before deciding affected files. Return the relevant file set and uncertainties; do not read every module or import the app for discovery.

For a handoff, read [HANDOFF](../../../HANDOFF.md). For environment work, read [ENVIRONMENTS](../../../docs/ENVIRONMENTS.md) and the named private access record; keep URLs, credentials and administrative network details out of public output. The issuer is a separate full project; deploy/license-server contains release components only and is excluded from tenant images. Verify image identities and overrides, not tags alone. Do not execute old financial drivers to reproduce historical documentation.
